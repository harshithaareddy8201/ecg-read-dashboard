# ecg-read-dashboard
Turns a raw ECG signal into plain-language advice for patients (English, Hindi, Kannada), with a doctor view. Python pipeline (NeuroKit2, scikit-learn) tested on 100,733 beats from 44 MIT-BIH patients: 98% of beats detected; 87% of ventricular beats caught on unseen patients. Prototype, not a medical device.
